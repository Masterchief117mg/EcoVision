# 🌱 EcoVision

EcoVision es una aplicación móvil desarrollada con Flutter que utiliza
Inteligencia Artificial y Machine Learning para clasificar residuos
a partir de imágenes.

## 📱 Características

- Captura de imágenes mediante la cámara.
- Selección de imágenes desde la galería.
- Clasificación automática de residuos.
- Porcentaje de confianza de la predicción.
- Historial de resultados.
- Modelo de Machine Learning ejecutado mediante TensorFlow Lite.

## 🧠 Inteligencia Artificial

El proyecto utiliza un modelo de Machine Learning exportado a TensorFlow Lite
para realizar la clasificación de imágenes directamente desde la aplicación.

## 🛠️ Tecnologías

- Flutter
- Dart
- TensorFlow Lite
- Machine Learning
- Inteligencia Artificial
- Procesamiento de imágenes
- Android

## 🎯 Objetivo

Facilitar la identificación de residuos mediante Inteligencia Artificial
y promover una correcta separación de los residuos.
